# Feature Notes

One markdown file per feature, written **before** the code.

Template:

```markdown
# <Feature>

## Problem
What player-facing need or v1 defect this addresses.

## Design
How it works. Include the data shape and which Bus signals it emits/consumes.

## Constraints
Which AGENTS.md rules apply, and any new Palette tokens required.

## Verification
How it's tested. New assertions in tests/.
```
